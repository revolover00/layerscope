01

Parse the tar

Headers are read sequentially with File.slice. Legacy (manifest.json) and OCI (index.json + blobs/) layouts are both recognized; gzip layers stream through DecompressionStream.

02

Diff each layer

Every layer is compared against the squashed filesystem below it: files added, modified or deleted — including .wh. whiteout files and .wh..wh..opq opaque markers.

03

Score it

Files overwritten or removed in later layers still occupy space in earlier ones. layerscope computes wasted bytes and an efficiency score with dive's formula, plus the 20 largest files.

Why files can be “wasted”

Docker layers are immutable. When a later layer overwrites or deletes a file, the old bytes stay in the earlier layer forever. dive and layerscope count every occurrence of a path across layers; an image is efficient when few paths appear in multiple layers. Wasted is dive's number — it deliberately includes the copy that still exists, which keeps layerscope comparable with dive. Reclaimable is the smaller number you actually get back if you flatten the image into one layer.

  • efficiencyΣ min(occurrence sizes) ÷ Σ cumulative sizes
  • wasted bytesdive's definition: total bytes of every path seen in ≥ 2 layers or deleted — surviving copy included
  • reclaimablewasted bytes − bytes of the copies that survive in the final squashed image
  • wasted %wasted bytes ÷ (image size − first layer)

Whiteouts of removed directories are sized from the squashed filesystem below them. Opaque markers (.wh..wh..opq) hide lower files without counting as deletions. Sizes are tar-header sizes; hardlinks count as 0.

layerscope

Analyze Docker images without uploading them. File contents are streamed past and discarded — only tar headers are read.

Limits

  • zstd layers — supported: natively where the browser provides it, otherwise via the bundled pure-JS decoder (one layer in memory). The oci-save-zstd fixture passes dive's golden.
  • Whole-archive .tar.gz of a docker save output is not supported — save with uncompressed layers.
  • Wasted-space math mirrors dive; see README for verified/unverified claims.
  • Compared against dive v0.13.1 on the CI sample images — numbers match exactly (see README).

Privacy

Everything happens locally in your browser tab. Nothing is uploaded, nothing is stored, no cookies, no analytics.
